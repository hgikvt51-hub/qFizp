1Сгорание аммиака

Дано
Δt = 1 мин
ΔC(NH₃) = 1,2 моль/л
C₀(N₂) = 0
Найти
v(NH₃) — ?
C(N₂) — ?
Решение
4NH₃ + 3O₂ → 2N₂ + 6H₂O
v(NH₃) = ΔC(NH₃) / Δt = 1,2 / 1 = 1,2 моль/(л·мин)
ΔC(N₂) = ΔC(NH₃) · 2/4 = 1,2 · 2/4 = 0,6 моль/л
C(N₂) = C₀(N₂) + ΔC(N₂) = 0 + 0,6 = 0,6 моль/л
Ответ: v(NH₃) = 1,2 моль/(л·мин); C(N₂) = 0,6 моль/л.

2Реакция кремния с кислородом

Si + O₂ → SiO₂
а) Концентрацию кислорода увеличили в 3 раза

Скорость реакции увеличится в 3 раза, так как кислород является исходным реагирующим веществом.

б) Измельчили кремний

Скорость реакции увеличится: при измельчении возрастёт площадь поверхности кремния, соприкасающейся с кислородом.

в) Измельчили оксид кремния

Скорость реакции не изменится. Оксид кремния — продукт реакции, а не исходный реагент.
