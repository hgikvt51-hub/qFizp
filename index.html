Скорость химических реакций

Решение с подстановками и ответами

1. Сгорание аммиака

Дано: за 1 минуту концентрация аммиака уменьшилась на 1,2 моль/л. Начальная концентрация азота равна нулю.

Δt = 1 мин
ΔC(NH3) = 1,2 моль/л
C0(N2) = 0

Найти: скорость расходования NH3 и конечную концентрацию N2.

Решение

Уравнение реакции:

4NH3 + 3O2 → 2N2 + 6H2O

Найдём скорость по уменьшению концентрации аммиака:

v(NH3) = ΔC(NH3) / Δt = 1,2 / 1 = 1,2 моль/(л·мин)

По уравнению из 4 моль аммиака образуются 2 моль азота. Поэтому увеличение концентрации азота:

ΔC(N2) = 1,2 · 2 / 4 = 0,6 моль/л

Начальная концентрация азота равна нулю:

C(N2) = C0(N2) + ΔC(N2) = 0 + 0,6 = 0,6 моль/л

Ответ: скорость расходования аммиака — 1,2 моль/(л·мин); концентрация азота — 0,6 моль/л.

2. Реакция кремния с кислородом

Si + O2 → SiO2

а) Концентрацию кислорода увеличили в 3 раза

В школьной модели принимаем, что скорость реакции прямо пропорциональна концентрации кислорода. Тогда:

v2 = 3v1

Ответ: скорость увеличится в 3 раза.

б) Измельчили кремний

Кремний — твёрдый реагент. При измельчении увеличивается площадь его поверхности соприкосновения с кислородом, поэтому реакция идёт быстрее.

Ответ: скорость увеличится.

в) Измельчили оксид кремния

Оксид кремния SiO2 — продукт реакции, а не исходное вещество. Его измельчение не увеличивает площадь соприкосновения исходных реагентов.

Ответ: скорость реакции не изменится.
