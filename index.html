Тема: скорость химической реакции

Скорость реакции показывает, как меняется концентрация вещества за промежуток времени.

Средняя скорость: v = ΔC / Δt; Δt = t₂ − t₁.
Для исходного вещества: ΔC = C₁ − C₂. Для продукта: ΔC = C₂ − C₁. Поэтому ΔC и скорость берём положительными.
Единицы: моль/(л·с), моль/(л·мин) и т. п.

Закон действующих масс для приведённых в заданиях реакций: если aA + bB → продукты, то v = k·C(A)a·C(B)b. В заданиях ниже используем принятую в школьных примерах модель: показатели степеней берём по коэффициентам уравнения; для гетерогенных реакций концентрацию твёрдого вещества не включаем. Это учебное приближение, а не универсальное правило для любой реакции.

Температура (правило Вант-Гоффа): v₂/v₁ = γ(T₂−T₁)/10, где γ — температурный коэффициент. При повышении на каждые 10°C скорость возрастает в γ раз; при охлаждении на 10°C делится на γ.

Катализатор ускоряет реакцию, сам не расходуется; ингибитор замедляет, сам не расходуется. Катализатор даёт альтернативный путь с меньшей энергией активации.

Гетерогенная реакция: в CO₂ + C(тв.) → 2CO концентрация твёрдого углерода не входит в выражение скорости; в простейшей модели v = k·C(CO₂).

Проверенные примеры по теме

Пример со слайда: сгорание сероводорода

Дано: Δt = 1 мин = 60 с; ΔC(H₂S) = 0,6 моль/л; C₁(O₂) = 1,2 моль/л.

Найти: скорость расходования H₂S и конечную концентрацию O₂.

Решение:
2H₂S + 3O₂ → 2SO₂ + 2H₂O
1) Скорость расходования реагента: v(H₂S) = ΔC / Δt = 0,6 моль/л / 60 с = 0,01 моль/(л·с).
2) По коэффициентам: 2 моль H₂S : 3 моль O₂ = 0,6 моль/л : x.
x = 0,6 · 3 / 2 = 0,9 моль/л; это ΔC(O₂).
C₂(O₂) = 1,2 − 0,9 = 0,3 моль/л.
Ответ: v(H₂S) = 0,01 моль/(л·с); C₂(O₂) = 0,3 моль/л.

Температурный коэффициент γ = 3

Дано: ΔT = 50°C; γ = 3. Найти: во сколько раз изменится скорость.

v₂/v₁ = γΔT/10 = 350/10 = 3⁵ = 243
Ответ: скорость увеличится в 243 раза.

2NO + O₂ → 2NO₂: изменение концентрации NO

По закону действующих масс v = k·C(NO)²·C(O₂). Если концентрацию NO увеличить в 5 раз, а прочие условия не менять:

v₂/v₁ = (5·C(NO))² / C(NO)² = 5² = 25
Ответ: скорость увеличится в 25 раз.

CO₂ + C(тв.) → 2CO

Скорость в этой гетерогенной реакции зависит от концентрации газообразного CO₂ и площади поверхности углерода. Количество твёрдого углерода как концентрация в закон скорости не подставляют.

v = k·C(CO₂)

1. Сгорание метана

Дано: Δt = 5 мин; концентрация CH₄ уменьшилась на 0,5 моль/л; C₁(CO₂) = 0.

Найти: среднюю скорость расходования CH₄ и C₂(CO₂).

Решение:
CH₄ + 2O₂ → CO₂ + 2H₂O
1) Скорость расходования реагента: v(CH₄) = ΔC / Δt = 0,5 моль/л / 5 мин = 0,1 моль/(л·мин).
2) По уравнению реакции: 1 моль CH₄ : 1 моль CO₂ = 0,5 моль/л : x.
x = 0,5 · 1 / 1 = 0,5 моль/л; это ΔC(CO₂).
C₂(CO₂) = C₁ + ΔC = 0 + 0,5 = 0,5 моль/л.
Ответ: v(CH₄) = 0,1 моль/(л·мин); C₂(CO₂) = 0,5 моль/л.

2. Температурный коэффициент γ = 1,5

Дано: γ = 1,5; повышение температуры на 20°C и понижение на 30°C.

Найти: отношение скоростей для обоих случаев.

Решение:
Формула Вант-Гоффа: v₂/v₁ = γ^((T₂−T₁)/10).
а) Повышение на 20°C: v₂/v₁ = 1,5^(20/10) = 1,5² = 2,25.
б) Понижение на 30°C: v₂/v₁ = 1 / 1,5^(30/10) = 1/1,5³ = 8/27 ≈ 0,296.
Ответ: а) скорость увеличится в 2,25 раза; б) уменьшится в 3,375 раза.

3. 2NO + O₂ → 2NO₂

Дано: [O₂] увеличили в 5 раз; отдельно [NO] увеличили в 5 раз; другие концентрации не меняются.

Найти: во сколько раз изменится скорость.

Решение:
v = k·[NO]²·[O₂]. Пункты рассматриваем отдельно.
а) Меняется только O₂: v₂/v₁ = 5.
б) Меняется только NO: v₂/v₁ = (5[NO])²/[NO]² = 5² = 25.
Ответ: а) в 5 раз; б) в 25 раз.
